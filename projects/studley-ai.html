Studley AI Study Tool Replica

A self-contained HTML study application built to explore core study and revision functionality using the Claude API.

Prototype / learning projectMohammed Mirshan · Selected work

Project idea

Studley AI Study Tool Replica was an independent exercise to explore how a focused study interface could support learning and revision. The work centred on building a self-contained HTML application and experimenting with AI-assisted interactions.

Areas explored

  • Structuring a single-page study interface.
  • Using HTML, CSS and JavaScript to organise learning interactions.
  • Exploring Claude API integration for AI-assisted study functionality.
  • Thinking through how a learner moves between prompts, material and revision tasks.

Current status

This is presented as a learning prototype. It is not represented as an official Studley product, a commercial release or a maintained production application.
